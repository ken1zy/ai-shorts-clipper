# AI Shorts Clipper

Скрипт для автоматического нарезания вертикальных Shorts/Reels из длинных видео (мультики, подкасты и т.д.).

## Идея

1. Отправляем видео в Gemini — модель находит самые «вирусные» моменты по таймкодам.
2. Притягиваем границы клипов к склейкам сцен (PySceneDetect).
3. Собираем кадр 9:16 через FFmpeg и нормализуем звук под платформы.

## Стек (план)

- Python 3.11+
- Google Gemini API
- FFmpeg
- PySceneDetect, Pydantic

## Статус

Проект в начальной стадии — настраивается окружение и базовая структура.
